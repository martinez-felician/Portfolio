TiTennis Mobile App

An Android app that connects tennis players and helps them find hitting partners in their area. Built as my Senior Project using Android Studio, Java, PHP, and MySQL.

About the Project

For my Senior Project I decided to build an app that would connect tennis players and help them find a partner to play with. Throughout this process I had to learn full-stack mobile development on my own — from designing the database schema in MySQL Workbench to building the Android UI in Java and creating the PHP backend API that ties them together.

The experience taught me how to manage a full product lifecycle: planning features, setting up the backend, designing the UI screens, and testing the full flow end-to-end.

Skills & Technologies

Android Development
Built the full Android UI using Java in Android Studio, including login, signup, home, player map, and user profile screens.
Backend with PHP & MySQL
Designed the database schema in MySQL Workbench and wrote PHP scripts to handle API requests from the app — user authentication, registration, and player lookup.
Full Stack Architecture
Connected a native Android frontend to a remote PHP/MySQL backend, learning how to structure RESTful endpoints and handle network requests in Java.
Project Management
Managed the full development lifecycle independently — planning, designing, implementing, testing, and presenting the final project.
