Titanic Survival Analysis

An exploratory data analysis of the Titanic dataset written in R Markdown. Investigates the factors that influenced passenger survival — including class, gender, and age — through statistical summaries and data visualizations.

GitHub

About the Project

This report analyzes the Titanic passenger dataset to understand what factors determined survival during the disaster. Using R Markdown, the analysis combines narrative text, code, and visualizations into a single reproducible document exported as both HTML and PDF.

The report explores survival rates across passenger class, gender, and age groups, uncovering patterns such as the strong influence of gender and socioeconomic class on survival probability. All visualizations were built with ggplot2 and the analysis follows a structured EDA workflow.
