Brick Breaker

A classic Brick Breaker game built in C++, developed alongside a custom game engine co-designed with my class. Covers rendering, physics, and collision detection fundamentals.

View Source Code

What I Learned

C++ & Object-Oriented Programming
Structured the game using classes and objects for the ball, paddle, and brick entities. Leveraged shared game engine libraries.
Windows API
Managed the game window, device context, and Windows message handling for painting and activation events.
Game Loop & Frame Rate Management
Implemented a game loop that updates ball physics and paddle position while rendering frames at a consistent rate.
Graphics & Rendering
Loaded and drew bitmap assets, managing rendering of the ball, paddle, and brick grid.
Game Engine Utilization
Set up and integrated the shared game engine, configuring game resources and initial state.
Input Handling
Handled keyboard input for paddle movement left and right.
Collision Detection & Response
Detected and responded to collisions between the ball and bricks, paddle, and walls — including angle-of-reflection physics.
Game State Management
Managed win, lose, and active gameplay states through flags and message boxes.
