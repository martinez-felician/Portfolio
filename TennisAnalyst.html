Tennis Analyst

A full-stack web app to track tennis match statistics in real time, analyze performance, and generate personalized 3-day practice plans based on your weaknesses. Deployed on PythonAnywhere and installable as a PWA on iPhone.

Live App GitHub

About the Project

Tennis Analyst was built to solve a real problem — tracking match performance manually is difficult in the middle of a game, and without data it's hard to know what to actually practice. I built this app to track every point in real time, log winners and errors by shot type, and automatically generate a targeted practice plan at the end of each match.

The app handles full tennis scoring rules including deuce, advantage, tiebreaks (first to 7 or 10), and configurable match formats (Best of 1/3/5). After the match, the Insights tab analyzes your stats and produces a personalized 3-day practice plan with specific drills, durations, and coaching cues.

Skills & Technologies

Flask Backend & REST API
Built a Python Flask server with RESTful API routes for user authentication, match saving, and match history retrieval. Passwords are hashed using Werkzeug's PBKDF2 implementation.
SQLite Database
Designed a normalized SQLite schema with a users table and a matches table. Match config, stats, and result are stored as JSON, allowing flexible querying and replay.
Vanilla JavaScript Frontend
The entire UI is built with plain HTML, CSS, and JavaScript — no frameworks. State is managed through global variables and a multi-step point-entry flow that handles the full rules of tennis scoring.
Progressive Web App (PWA)
Added a Web App Manifest, service worker, and iOS meta tags so the app can be installed directly to an iPhone home screen from Safari — full screen, no browser bar.
Deployment
Deployed to PythonAnywhere using a WSGI configuration. The project is version-controlled on GitHub with continuous deployment via git pull.
