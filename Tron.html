C++ · Windows API · Game Dev

LightCycles (Tron)

A Tron-inspired LightCycles game built in C++. Part of the design included building the game engine itself alongside my class, covering everything from graphics rendering to collision detection.

View Source Code

What I Learned

C++ & Object-Oriented Programming
Structured the game using classes and objects. Implemented and consumed external game libraries.
Windows API
Interacted with Windows-specific functions and data types (HINSTANCE, HWND, HDC) to manage the game window and rendering context.
Handled Windows messages for events like painting and window activation.
Game Loop & Frame Rate Management
Designed a game loop that handles state updates and frame rendering at a consistent rate for smooth gameplay.
Graphics & Rendering
Loaded and drew bitmaps, managing different character orientations for the LightCycle sprites.
Game Engine Utilization
Initialized, configured, and integrated a shared game engine developed alongside the class. Set up resources, bitmaps, and game state initialization.
Input Handling
Handled keyboard input for directional movement of the LightCycle character.
Collision Detection
Detected and handled collisions between trails and cycles to determine game-over conditions.
Game State Management
Managed different game states — start screen, active gameplay, and end screen — using message boxes and state flags.
